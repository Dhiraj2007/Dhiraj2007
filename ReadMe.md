# 💫 About Me:
Senior DevOps and Cloud Engineering professional with 8+ years of experience in DevOps implementation, Site Reliability Engineering (SRE), cloud infrastructure, CI/CD automation, configuration management, and enterprise application deployments. Experienced in designing and maintaining automated delivery pipelines using Jenkins, GitLab CI/CD, and related DevOps tools, along with infrastructure provisioning and management using Terraform and Ansible.<br><br>Strong hands-on experience with AWS services, including EC2, S3, VPC, IAM, RDS, EKS, ECS, Lambda, and CloudWatch, complemented by Azure cloud exposure and experience supporting GCP-based environments. Skilled in automating deployments, managing WebLogic application releases, implementing infrastructure as code, troubleshooting production issues, and improving application reliability through monitoring and operational practices.<br><br>Proficient in scripting and automation using Bash, PowerShell, and Groovy, with working knowledge of Python. Experienced with containerization, Kubernetes-based environments, source control, artifact management, secrets management, and application monitoring using tools such as Datadog. Focused on building scalable, secure, reliable, and repeatable cloud and DevOps solutions for enterprise environments.
